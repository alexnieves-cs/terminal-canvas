Run coding agents side by side. Review every change.

Claude Code, Codex and plain shells each get a real terminal on one canvas. See which one needs you, review what each one changed, and keep control of the result.

Try the live demo Download for macOS

The demo runs in your browser with scripted agents and nothing to install. The app is an unsigned build for Apple Silicon and Intel Macs; install notes below.

Stop losing the agent that stopped to ask you something.

Coding agents run for minutes or hours, and the usual way to run several is a wall of terminal tabs. Terminal Canvas puts each agent in a real terminal on a canvas you arrange, and then does the bookkeeping.

Every panel is a real terminal

Each panel is a genuine PTY, so claude, codex or your own shell run exactly as they do anywhere else.

The canvas tells you who needs you

A panel's border carries its agent's state, an off-screen panel that is waiting gets an edge pip, and ⌘J flies to the next one.

Review is built in

Each panel is diffed against the snapshot taken when its agent started, so you see what that agent changed and commit it from the canvas.

One worktree per agent

Give each agent its own git worktree and branch, arrange them side by side, and merge deliberately. Four agents, four clean checkouts.

Agents that hand off work

Draw an edge from one panel to another: when the source finishes, the target starts with its output as context.

Work stays where you left it

With tmux installed, agents outlive a reload and, if you ask, a quit. The Sessions page shows what finished, failed or is waiting.

See it before you install it

The live demo is the app's own interface on a sample canvas. Agents work, wait for you and finish; terminals play recordings, and anything that would start a process says it runs in the app.

Install

  1. With Homebrew: 
    brew tap alexnieves-cs/terminal-canvas https://github.com/alexnieves-cs/terminal-canvas
brew install --cask terminal-canvas
    Or download the .dmg for your Mac (-arm64 for Apple Silicon, -x64 for Intel) from the latest release, open it, and drag Terminal Canvas to Applications.
  2. The build is unsigned, so macOS refuses the first launch. Open System Settings → Privacy & Security and choose Open Anyway, or clear the quarantine flag: 
    xattr -dr com.apple.quarantine /Applications/Terminal\ Canvas.app
  3. Install tmux (brew install tmux) if you want agents to survive a reload or a quit. It is optional.

Only skip the warning because you have read the source or trust its author: the app, by design, runs whatever commands you give it. Prefer to build it yourself? The build from source steps are four commands. New here? The user guide starts with your first task.
