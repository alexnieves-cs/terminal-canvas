# Changelog

Each release's full notes live in [docs/release-notes/](docs/release-notes/).

## 7.0.0 (in progress)

Not released. 7.0 is a signed public launch with a feedback loop, and the version stays 6.2.0
until it ships. Built so far: a signed copy can download and install a newer release after you
choose Download and install, and an unsigned copy still only links to the release. Crash
reports read the project's address from the build and send nothing until you turn them on. An
optional tally of which features you use stays on your Mac, and you can copy or clear it from
the palette. The first signed release waits on the Apple Developer secrets; see
[docs/release-signing.md](docs/release-signing.md).

## 6.2.0

The wrap-up release. The website, live demo and user guide are live on GitHub Pages. An
accessibility pass fixed keyboard flow, landmarks, headings, contrast and the Review page. Relay,
Jira and Sheets are removed. A bug review fixed palette ranking, the onboarding name, the usage
chart across a clock change, pricing and the hosted Open/Save dialog, and the flaky
`verify:canvas` wheel checks were fixed at the root. [Notes](docs/release-notes/6.2.0.md).
