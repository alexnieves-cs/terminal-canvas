# Changelog

Each release's full notes live in [docs/release-notes/](docs/release-notes/).

## 6.2.0

The wrap-up release. The website, live demo and user guide are live on GitHub Pages. An
accessibility pass fixed keyboard flow, landmarks, headings, contrast and the Review page. Relay,
Jira and Sheets are removed. A bug review fixed palette ranking, the onboarding name, the usage
chart across a clock change, pricing and the hosted Open/Save dialog, and the flaky
`verify:canvas` wheel checks were fixed at the root. [Notes](docs/release-notes/6.2.0.md).
