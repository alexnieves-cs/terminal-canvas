# The verify suites, check by check

Split out of `CLAUDE.md` so it is read on demand rather than loaded into context
on every prompt. `CLAUDE.md`'s `## Commands` section carries the compact index —
suite, runtime, check count, coverage — and this file carries the narrative each
row used to hold: which checks are worth knowing BY NUMBER, what each one would
fail against, and which were fault-injected.

**Search it, don't scroll it.** Every row begins `| \`verify:<name>\``, so:

```sh
grep -n 'verify:panels' docs/verify-suites.md
```
