# Terminal Canvas 6.0.0

The redesign (M435–M456). The visual language changed. A chord that moved keeps its previous binding as a hidden alias for this release.

This build is not signed. On first launch Control-click the app and choose Open, or run `xattr -dr com.apple.quarantine "/Applications/Terminal Canvas.app"`.

The DMG will be attached after a Mac package pass. This release has no disk image.

## What changed, screen by screen

The pictures are `docs/redesign/mockups/`. Sample names in those pictures
(Steward, ledger-export, dollar amounts) are fixture copy, not product copy.

| # | Screen | What a person sees now |
|---|---|---|
| 01 | Launch / restore | A dark card over the canvas: the mark, "Every agent, in its place.", and an honest checklist (workspace, layout, reattaching tmux, agents). Hold ⌥ to skip reattaching. |
| 02 | First run | Onboarding walks Workspace → Agents → Sessions → First task. Agents on PATH can be toggled. A missing tool offers its install command. A preview teaches the state colours before the first session. |
| 03 | Empty canvas | One primary verb, quick spawns, and three inert starter layouts. The minimap says "Nothing placed yet" and shows no zero. A double-click on empty canvas still places a flowchart step (R-024). |
| 04 | Main workspace | Work tier. Task regions, a needs-you panel with Allow / Diff / Deny, handoff edges, the inspector, the zoom HUD, the minimap, and the attention pill. Selection is a cyan ring on a working panel, so the two facts stay distinct (D1). |
| 05 | Create and arrange | Dragging from a port opens a connected spawn. Smart guides use the 24px gap. A marquee brings up Align, Tidy, Make task (⌘G), and Pause all. |
| 06 | Navigate | Plan tier (about 34%) turns panels into status cards and shows task territories. ⌘K is grouped (panels and tasks, commands, files) with fly-to and fit-task. Map tier is the same canvas as dots. The Work / Plan / Map switch sits with the zoom HUD. |
| 07 | Sessions | A triage page, not a tab that blanks the canvas. An attention queue, a table grouped by task (run, cost, and last line are allowed here — D3), a bulk bar, and a detail pane. The spend total lives in this header, not in the title bar. |
| 08 | Settings › Keyboard | The shortcut map, a conflict when an agent's own ⌘K would steal the palette, and a shortcut recorded inline. Focus lock is ⌘⇧L: the terminal then gets every key (D4). |
| 09 | Error and disconnected | A host-loss banner that says paused, not lost. A crashed session explains itself with one fix. Reattaching panels are skeletons. Stale GitHub data is marked. The pill switches to recovery. |
| 10 | Canvas → World | About a second, frozen in the shot at 550ms: the plan tips back, terraces rise, a cancel chip, the 2D \| World lens, and a filmstrip. Reduced motion is a 120ms cross-fade, not a dolly. |
| 11 | The World | The same layout stood up. Terraces sit at the canvas coordinates. State colour matches the canvas (D7 reversed the old green-means-working). Waiting agents raise a beacon where they stand. Without WebGL the flat room keeps the same words and doors. |
| 12 | Focus and act | Picking an agent glides in. A sheet holds the ask, Approve / Deny, facts, a reply for a chat agent, and Open in Canvas. A plain shell is not answered from the room. |
| 13 | Attention flight | ⌘J walks the same queue as the canvas. A strip shows which of the waiting agents is current. Approve sends immediately. Undo appears only when a review can still discard that change (D9). |
| 14 | Overview | Map tier, near top-down. A camera panel (orbit, pan, zoom, ⌘1/2/3, fit, follow, back to 2D). A replay scrubber. Past rooms keep the verbs and disable them. |

## Class aliases

A restyle keeps the selectors the suites already use. Nothing in these families
was renamed between `pre-redesign` and this branch. New shell classes were
added beside them (`shell__avatar`, `shell__nav-badge`, `shell__page`,
`shell__sessions`).

| Family | Still works |
|---|---|
| `.panel__*` | Yes. Every selector that existed at `pre-redesign` is still in the tree (the slot, the chrome, the card, the header). |
| `*-node__*` | Yes. `browser-node`, `checklist-node`, `deck-node`, `file-node`, `github-node`, `image-node`, `jira-node`, `memory-node`, `note-node`, `relay-node`, `review-node`, `sheet-node`, `skill-node`, `subagent-node`, `toolbox-node`, `watcher-node`, `workflow-node`, `work-node`. |
| `.shell__*` | Yes. The center control, the rail, the inspector, the dock, and the merge control keep their old class names. Orchestrate stays a clipped segment inside `.shell__center-toggle` so older harness clicks still find it. The doors a person uses are Canvas, Sessions, and Review. |

`.pf__body` is still not transformed.

## Decisions

| | |
|---|---|
| D1 | Cyan is working. Selection is a lighter cyan ring plus the inspector, so a selected working panel is still two facts. |
| D2 | The center control is Canvas \| Sessions \| Review. Orchestrate stays in the View menu, the palette, and a Sessions link. World is a lens, not a tab. |
| D3 | Sessions may show run and cost. The title bar does not show a dollar amount. It may show a session count. |
| D4 | The canvas owns ⌘K unless the focused panel is focus-locked (⌘⇧L), in which case every key goes to the terminal. |
| D5 | New chords live in `src/shared/shortcuts.ts`. The old Tidy chord stays as a hidden alias for one release. |
| D6 | World ships on, with a WebGL probe and the flat room when the probe says no. |
| D7 | Finished-OK facts use the done tone (green). Idle is slate. The words did not change. |
| D8 | The version is 6.0.0, because the visual language changed, with the chord migration note in D5. |
| D9 | Approve sends immediately. The toast offers Undo only when a review discard can revert that panel. Otherwise it says the edit was approved and offers View diff. |
