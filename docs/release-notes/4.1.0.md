# Terminal Canvas 4.1.0

Unsigned macOS build (Apple Silicon). Gatekeeper will object the first time; the README's
Install section says what it will say and what to do. Nothing in this release phones home:
the update notice (3.0) stays off by default.

## What is new since 4.0

4.1 is a polish release: nothing the app can do changed, and everything it shows at rest did.
The run's brief (`docs/superpowers/specs/2026-09-07-m162-product-polish-brief.md`) states
five rules — the face rule, the rest rule, the path rule, the metrics rule, and words rather
than codes — and every surface now answers to them.

- **The frame.** A panel header at rest is its kind's glyph, its title and one state. The
  `⋯` menu, the marks, the kind's verbs, `fill` and `×` appear when the frame is hovered,
  focused or selected. The `CPU · RAM` readout lives in the inspector's Machine section. The
  dark theme's panels lift one clear step from the field.
- **The body.** Review, file, toolbox, skill, work, memory, note and GitHub bodies read as
  prose — the system face at 14px, a reading inset, a 72-character measure — with code,
  diffs, paths and ids in mono. Paths show the repository's basename and the path relative
  to it; the full path is on hover. Diffs are cards: the file's name, `+n −n` pills, the
  hunk washed, `discard` on hover. At a fifth of the size every card is a glyph, a name and
  a state wash.
- **The conversation.** A chat panel looks like the conversation it is: the user's turn a
  soft bubble, the assistant's prose rendered from markdown (headings, lists, fences with a
  copy verb, inline code), tool calls one collapsed row each — glyph, verb, target, state —
  and consecutive calls folded under one header. The composer is a rounded well with a
  chips row and one filled Send; Interrupt takes its place while a turn runs; an approval
  is a sentence and two buttons in the well. A `claude` terminal wears the chat's header.
- **The shell.** The Panels list groups its rows by what they are (Agents, Files, Reviews,
  Boards, Integrations, Workflows) with a glyph, a name and a state dot; `start` on hover.
  The dock's buttons name their places on hover; the live/quiet capsules are gone. The
  status bar is a floating zoom pill and nothing else; the tmux notice is a first-run banner
  in the launcher and a line in the environment report; the hint strip is gone and its
  hints are the empty state's. The launcher is a welcome: the title in the system face,
  three doors, a recents row, a quiet verb list, one calm environment sentence.
- **The finish.** Five moments of motion and no others, every duration a token, all removed
  under reduced motion. Every empty state says what its surface is for and offers a verb.

## What did not change

xterm's cells, the PTY layer, dormancy, the WebGL budget, every IPC channel (124), every
data format on disk. A 4.0 layout opens unchanged.

## Known bounds

- The file and toolbox panels show a directory's last two segments rather than
  `repo/src` — they know no repository root yet (backlog #86).
- A chat's markdown parse re-runs per streaming delta on the live row; ~150 ms on a 48 KB
  paragraph of stars (recorded, not a defect in ordinary prose).
- The canvas re-renders on mousemove for a cursor readout that no longer exists (backlog
  #87).
