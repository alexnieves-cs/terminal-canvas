# Terminal Canvas 6.0.1

The streams run (M457–M518) on top of the 6.0 redesign, and the first release built by
`release.yml`: a `v*` tag becomes this page, and its DMG is the one that passed
`verify:packaged` on the same macOS runner.

This build is not signed. On first launch Control-click the app and choose Open, or run
`xattr -dr com.apple.quarantine "/Applications/Terminal Canvas.app"`.

## What is new since 6.0.0

- **It tells you when a newer release is out.** Once per launch the app asks GitHub's public
  releases list whether there is a newer, non-prerelease version, and shows a notice with a
  link when there is. Nothing is downloaded or installed. Settings → `update.checkOnLaunch`
  turns it off (M474).
- **Overnight work.** Auto runs finish on a passing check, not on the agent's word (M475–M476).
  Tonight batches run one auto run at a time, pause at your limits and keep the Mac awake
  (M477). In the morning, a queue shows what finished, and a collision radar flags two lanes
  touching the same files. Accept merges the commit that was checked (M478–M481).
- **Reach.** `tc mcp` is a stdio MCP server over the control socket, so another agent can read
  the canvas. It can also answer an approval or accept a lane, behind the same gates (M487–M488).
  Phone alerts go through ntfy when an agent needs you (M489).
- **Fewer doors by default.** Accounts and sharing, relay terminals, decks, sheets, the Jira
  panel, and the Toolbox and Memory panels are off until you turn them on in Settings. Nothing
  was removed, and an object already on a canvas keeps working. World stays on (M496).
- **Polish.** Status at a glance, press feedback, and Sessions, inspector, onboarding and settings
  passes (M511–M517). Coloured edge stripes are gone, and the canvas has a drafting-paper
  texture (M518). Follow sits in the HUD, terminal memory has a cap, and command panels
  arrived (M497, M508, M509).
- **Under the hood.** `Canvas.tsx` was split below 4,000 lines with no change in behaviour
  (M498–M507). A `tc open` sent while the window is still loading now spawns, where before
  it was acknowledged and then dropped (M468).

The full run-by-run story is in `docs/build-log/m457-m509-ledger.md`.
