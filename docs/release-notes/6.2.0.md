# Terminal Canvas 6.2.0

The wrap-up release: an accessibility pass, a round of bug fixes, Relay removed for good, a
steadier test suite, and the website, live demo and user guide online. Built by `release.yml` like 6.1.1. This build is
not signed yet, so the first launch needs Open Anyway (the install steps above say how).

## Online

- **The website, the live demo and the user guide are live** on GitHub Pages:
  [website](https://alexnieves-cs.github.io/terminal-canvas/),
  [live demo](https://alexnieves-cs.github.io/terminal-canvas/demo/) and
  [docs](https://alexnieves-cs.github.io/terminal-canvas/docs/). The README links to all three.

## Accessibility and polish

- **Keyboard:** the first Tab press reaches the app again. Hidden menu focus guards no longer
  take tab stops while nothing is open (M645).
- **Screen readers:** panels no longer each announce a banner landmark, the canvas view has a
  heading, the inspector's headings are in order, and rows read as separate words ("vitest
  watch idle", not "vitest watchidle") (M645).
- **Contrast:** state text in Sessions and the selected palette row's hint meet contrast in light
  and dark (M645).
- **Review page:** laid out like Sessions, with its rows as cards, and the Orchestrate button
  matches the primary button (M645).

## Removed

- **Relay terminals** are gone, with their server, channels and lab switch. A saved relay panel
  is dropped on load with a warning that says why (M685).
- **Jira and Sheets** are gone. Saved board items that came from Jira still read (M683, M684).

## Fixes

- The command palette ranks a row whose visible title matches above one that matches only on
  hidden words, and its rows no longer go stale while it is open (M690).
- The onboarding card keeps the workspace name, and the first-canvas guide counts only
  terminals and chats as agents started (M690).
- The week's usage chart keeps every day across a clock change, and the current Claude models
  are priced (M690).
- "60 min ago" and "24 h ago" no longer appear just under the hour or the day (M690).
- Enter submits the path field in the hosted Open and Save dialog (M690).

## Under the hood

- `verify:canvas` waits for the camera instead of a fixed sleep, so its wheel-pan and
  zoom-anchor checks no longer fail at random on a slow runner (M691).
- The `approval` and `verbs` screenshot scenes wait for the chat to settle before the capture
  (M693), and the shared-workspace scenes keep the teammate's terminals clear of the first-run
  card (M685).
- A new `verify:a11y` suite guards the accessibility fixes (M645).
