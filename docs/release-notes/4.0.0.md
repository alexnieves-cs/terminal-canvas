# Terminal Canvas 4.0.0

Unsigned macOS build (Apple Silicon). Gatekeeper will object the first time; the README's
Install section says what it will say and what to do. Nothing in this release phones home:
the update notice (3.0) stays off by default.

## What is new since 3.1

- **Tags on the vault.** `#tag` in a note is a chip; the Vault pane lists every tag with its
  count and filters by one; a chip filters from the other side. Wikilinks and backlinks were
  already there.
- **Ink.** In annotate mode, a `draw` tool: drag to draw on the canvas or on a panel — a
  stroke on a panel moves with it — select it, Delete it, and it is there after a relaunch.
- **The toolbox opens its files.** Every command, hook and MCP row has an Open door into the
  file editor — a deliberate edit, never a toggle.
- **Prompt placeholders.** `{{cwd}}`, `{{branch}}`, `{{selection}}`, `{{panel}}` fill from the
  target before any question is asked.
- **Cost history.** The no-selection summary's `this week` line, read from the run ledger.
- **Zoom-independent chrome.** Panel headers and resize handles keep their screen size as
  you zoom out; the terminal body never reflows.
- **Images into a terminal.** Paste a screenshot into a spawned terminal and the agent is
  handed a path.
- **Zoom to fit.** Frames the selection, or every panel, as a flight; `Reset zoom` stays.
- **Per-preset environment** (`KEY=value` in the sheet or on a preset) and **workspaces from
  a template**.
- **Fixed by the 4.0 audit:** the attention popover, invisible since 2.3.0; the panel `⋯`
  menu over a live terminal; the template sheet that stranded you in an empty workspace; the
  week line that never read the ledger; a preset's environment that never reached the
  process.
