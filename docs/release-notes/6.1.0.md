# Terminal Canvas 6.1.0

The bold directions run (lanes G–Q), the UI gaps audit (lane U) and the scale audit (lane V)
on top of 6.0.1. Built by `release.yml` like 6.0.1: the DMG is the one that passed
`verify:packaged` on the same macOS runner.

This build is not signed. On first launch open it from System Settings → Privacy & Security →
Open Anyway, or run `xattr -dr com.apple.quarantine "/Applications/Terminal Canvas.app"`.

Several of the new features change how agents run, so they start off and are turned on in
Settings. Each item below says which.

## What is new since 6.0.1

- **More agents, answered from your phone.** Gemini CLI, OpenCode, Cursor Agent, Amp and Kimi
  are built in. A phone alert can carry Allow once / Deny (`remote.phoneAnswers`, off by
  default). ⌥⌘Y allows every pending read at once. Claude chats show exact states from
  per-panel hooks, and `tc view <file|url>` opens a file or page on the canvas (M530–M535).
- **Cloud lanes.** Hand a task to a cloud agent (the Copilot coding agent or the Claude GitHub
  Action), follow it on its card, and merge it through the morning queue and the collision
  radar. Every write to GitHub is confirmed and scrubbed first (M541–M545).
- **Tournament mode.** One task runs on two to six agents at once, each in its own worktree
  with a checked auto run. The check decides who is eligible, a bracket shows the field, and
  Pick makes the winner the task's lane. Judge opens a read-only comparison (M546–M549, M606).
- **Sandboxed lanes.** Tonight batches and auto runs can put a task in a throwaway micro-VM
  (Apple container, OrbStack or Docker) with prompts off. The VM sees only the lane's
  worktree, and its only way out is an allowlisting proxy in the app that logs every
  connection. Off by default (`vm.lanes`). Confirming it on a real Mac is still listed as a
  manual check (M550–M555).
- **Fork from any turn.** With "Snapshot each agent turn" on (off by default), each finished
  turn is kept in hidden git refs. Replay's "Branch from here" starts a new worktree and chat
  from that turn and compares the two (M556–M560).
- **The night as a film.** "Render last night as a film" turns a Tonight batch and the ledger
  into a 60-second MP4, drawn and encoded in the app. Every caption passes the outward gate
  first (M561–M564, M607).
- **A harness that learns.** A discarded file or a review comment you send becomes a lesson.
  An agent can draft one CLAUDE.md line or skill from a group of lessons, prove it by replaying
  the task in a scratch worktree, and only a rule that holds can be accepted. Retire takes it
  back out. Drafting and proving are off until `learn.agents` is on (M570–M579).
- **Multiplayer handoffs.** On a shared canvas you can hand an agent to a teammate, offer it
  to anyone, or put a result in the team's review queue. Needs you shows what was handed to
  you and what waits on your team. Sharing stays behind `labs.accounts` (M580–M583).
- **The app outside the Mac.** A live demo of the renderer runs in the browser on a sample
  canvas (https://alexnieves-cs.github.io/terminal-canvas/). The real app can also be hosted
  on a Linux server and opened from a browser tab behind a token gate; `docs/hosted.md` and
  `deploy/host/Dockerfile` say how (M565–M569, M590–M594). Neither is part of the DMG.
- **UI gaps fixed.** Readable secondary text, focus that stays in the palette, Settings and
  Onboarding, a top bar that flows instead of overlapping, one empty-canvas story, a Review
  page that lists what came back with Lessons beside it, an inspector that shows the next
  step, and Sessions that leads with what needs you (M600–M610).
- **Under the hood.** One broker-refusal sorter for every GitHub client fixes a write nobody
  was asked about reading as "unavailable" (M615). One plain-object guard, one atomic file
  write and one log trim replace many copies (M616–M617). CLAUDE.md's IPC list is generated
  from the contract (M618). The orchestration page and the palette commands are split into
  parts, and every "how long ago" reads one formatter, so a few ages now say `4 min ago`
  (M619–M621).
- **CI.** Every suite blocks, `verify:visual` included, and the Mac checks that flaked were
  fixed at their cause rather than retried (M463, #75–#79).
- **Security.** The secret scrubber now also catches Stripe, Google, GitLab, npm and Hugging
  Face keys and a password inside a URL. The main window opens only http(s) links outside the
  app. Dependencies with published advisories were updated (#88).
- **Signing is wired, not on.** `release.yml` signs and notarizes when the Apple secrets are
  present; without them it builds unsigned as before (M630). The repository also has a landing
  page now.

The run-by-run story is in `docs/build-log/m457-m509-ledger.md`, under lanes G–V.
