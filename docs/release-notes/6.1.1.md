# Terminal Canvas 6.1.1

A short release that makes the install work on every Mac and makes the first ten minutes easier.
Built by `release.yml` like 6.1.0. This build is not signed yet, so the first launch needs Open
Anyway (the install steps above say how).

## Install on any Mac

- **Intel Macs get their own DMG** beside the Apple silicon one (M631).
- **Homebrew:** `brew install --cask alexnieves-cs/terminal-canvas/terminal-canvas`. The cask
  and the README point at versionless download names, which 6.1.0 did not publish. This
  release is the first that has them.

## The first ten minutes

- **Simple and Full.** The app now opens in Simple: the canvas, agents, terminals, attention,
  review, tasks and overnight runs. The 3D World view, tournaments, flowchart shapes, the night
  film and fork from a turn wait behind one switch (View menu, or the first choice in
  Settings). Nothing is removed, and any feature you had already turned on stays on (M642,
  M682).
- **Setup doctor.** The first-run card says how to install each missing agent CLI and how to
  sign in to one that looks signed out, with a Copy button and a Check again (M643).
- **A guided first canvas.** Three small steps: start an agent, jump to what needs you with
  ⌘J, open Review. Each one ticks itself off, and Skip ends the guide for good (M644).
- **Clearer UI.** The Canvas, Sessions and Review tabs no longer draw a halo across the top
  bar. A terminal's header shows its path only on hover, and Settings uses switches, menus
  and number fields that say what is wrong with a bad value (M641).

## Fixes

- Usage was counted twice for some sessions, and a long timer could overflow (M660).
- The git watcher missed some changes and some watchers could get stuck (M660).
- Layout notes are kept correctly across a reload (M660).
