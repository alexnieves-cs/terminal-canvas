## Decisions not visible in the diff

- **The order.** State vocabulary (M63) before finding (M64) and starting (M65), although
  the author listed starting first: the state word and edge are what the other two render.
- **Minimap and ad-hoc panels come back in**, both cut by the previous decision; the reasons
  are in the scope decision's §2. Lock/pin, focus-mode maximise, annotations, toolbox query
  and editing, placeholders, two windows, panes, images, time machine stay cut.
- **The dot grid and resting shadows go** — M45's own direction, which the implementation
  departed from. The brief overrules M45's implementation, not its argument.
- **The brief's signature is the state edge**, chosen because it is legible at every zoom,
  in both themes and in a thumbnail, and because M57's block tier already paints the same
  colour at far zoom — it is one idea extended, not a new one.
- **Considered and rejected for the brief:** a bundled UI face (CSP, and cell metrics racing
  a font load); a brand colour beyond iris (a second interface accent is the defect the
  critic found); animated state changes (a colour change is instant by principle).
