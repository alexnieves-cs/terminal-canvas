# M180 — a first conversation

Implement the first milestone of the approved v9 plan. The empty canvas presents one primary
conversation action using an available backend. It names which engines were found, gives
plain setup guidance when missing, and never equates installation with authentication.
A probe that has not answered must not tell a user to reinstall. Existing launcher aliases
and secondary actions survive; returning canvases remain untouched.

The shared readiness model consumes the existing environment report. A bounded agent control
door reaches approved data verbs through the same execution path as the UI; it rejects raw
commands, URL execution and unsupported actions by name. Four-door metadata records actual
coverage and the temporary workflow omission due at M189. Credential entry and approval
answers remain human-owned. No new dependency.

Repair the observed baseline image-paste failure by proving the exact written path reaches
the PTY irrespective of terminal line wrapping. Do not replace that property with mere file
existence. Installation/authentication and a timed first answer from a stranger remain hand
checks; deterministic checks use fake backend responses.
