# M194 / D02 — Selected chat context

Selecting a repository conversation must make its working folder available in Files and
Tools without creating a terminal. Today both hooks omit `ChatSource.cwd`, and the Tools
detail action omits chats too. Files also accepts replies from obsolete reads. Toolbox's
IPC handler uses the spawn resolver's home fallback for missing directories.

Selection owns inspection. Focus continues to own terminal path insertion: when those IDs
differ the inserted path is absolute and shell-quoted. Inspection creates, sends, interrupts
and disposes no execution session and grants no permissions. Toolbox discovery may run its
existing bounded CLI inventory probe; that is not an agent execution session.

Use a narrow pure directory policy shared by Files, Tools and its existing Open action.
Preserve terminal Files' live-cwd fallback, terminal Tools' configured cwd, review Files'
persisted repository root, and toolbox Tools' source cwd. Chats use their source cwd;
sandbox chats have no project folder even if their app-owned sandbox has a disk path.
No selection, a kind without a folder, and an unresolved folder have distinct explanations.

Async answers belong to a selection and directory, with Files also keyed by hidden-file
settings and refresh generation. A changed subject immediately masks the old answer, even
before effects run; late replies cannot repopulate it. Failed reads remain visible as failed
reads. Main validates Toolbox directories without falling back to home.

No persistence, migration, channel, permission, styling dependency or new verb. Existing
Files and Open toolbox doors are extended; no fourth-door addition is owed for a new verb.
Repository/worktree identity, preview ownership and other context consumers remain D03/D04.

Acceptance: A/B selection including an A→B→A late-reply race; sandbox, absent and unavailable
folders; terminal/review/toolbox compatibility; real path insertion with divergent focus;
no execution lifecycle changes; usable Open toolbox from chat. Inspect affected captures,
record critic sentences before golden updates, and pass the full verify, visual and packaged
gates. Inherited real-provider and physical-keyboard hand checks remain explicitly owed.
