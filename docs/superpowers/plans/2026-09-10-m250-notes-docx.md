# M250 plan — rich note editing and .docx import

Spec: [../specs/2026-09-10-m250-notes-docx.md](../specs/2026-09-10-m250-notes-docx.md).
Every task is test-first: its `verify:notes` checks are written and watched FAILING against the
missing module before the module exists.

1. **Dependencies.** `npm i -E mammoth@1.12.2 jszip@3.10.2`; `npm audit --omit=dev`, output in
   the ledger. `notes.deps.1` pins both as exact versions in `dependencies`.
2. **Fixtures.** `scripts/fixtures/build-sample-docx.cjs` writes `scripts/fixtures/sample.docx`
   with jszip from hand-written OOXML parts (fixed dates, so it rebuilds byte-identically —
   `docx.fixture.1`): a Heading 1, a bulleted list, a plain table, a table with a
   `w:gridSpan` merged cell, a PNG image, 2 comments, one `w:ins` and one `w:del`.
   `scripts/fixtures/md-corpus/*.md`: CommonMark oddities, tables, HTML, setext, reference
   links, front matter, trailing whitespace, tabs; CRLF and no-final-newline variants are made
   in-check so git's line-ending handling cannot hide a regression.
3. **`src/shared/md-blocks.ts`** — `parseBlocks`, `serializeBlocks`, `editBlock`,
   `replaceBlockSource`, `insertBlockAfter`, `blockRefusal`. Checks `notes.roundtrip.1–3`,
   `notes.raw.1–2`, `notes.edit.1`, `notes.list.1`, `notes.table.1`.
4. **`src/shared/html-to-md.ts`** — `htmlToMarkdown`. Check `html.1`.
5. **`src/shared/imported-note.ts`** — `ImportedNote`, `parseImportedNote` (absent / malformed /
   view), `importedNoteReason`, `lossSentence`; `FileSource.imported?`; one conditional spread
   in `layout-schema.ts parseFileSource`, `panels.ts makeFilePanel`, `layout-adapt.ts`
   `toPanels`/`fromPanels`, `portable.ts` export and import. Checks `notes.gate.1–3`.
6. **`src/main/docx-import.ts`** — `analyzeDocx` (jszip) and `importDocx` (injected read, stat,
   convert, putAsset, createFile). Checks `docx.convert.1`, `docx.asset.1`, `docx.loss.1`,
   `docx.readonly.1`, `docx.create.1`, `docx.refuse.1`.
7. **Channel `docx:import`** — `ipc-contract.ts` first, then `ipc.ts` handler with an INERT
   default collaborator, the real one in `index.ts` (dialog + `putAsset` + `createFile`), the
   preload bridge. `EXPECTED_CHANNELS` 134 → 135; the channel in CLAUDE.md's list and README's
   diagram (`claude-md.1`, `verify:meta 19`).
8. **Doors** — `import-docx` in `VERBS` + `V9_DOORS`, `'import-docx'` in
   `TEAMMATE_REFUSED_VERBS`, `importDocx` in `PaletteActions`, the `note.import-docx` row, the
   executor case, and the `.docx` arm in `dropPath`. `verify:verbs closure.v9.1` covers them.
9. **UI** — `RichNoteEditor.tsx` (blocks, list, table grid, link, image), the `Source | Rich`
   toggle in FileNode's edit mode for prose files, `noteEditorFocused()` in `shouldIgnoreKeys`,
   the import banner and the contextual loss line, the `read` verb's refusal. Styles beside
   `.file-node__editor`.
10. **Close** — `npm run verify` green with `TC_VERIFY_SUFFIX=m250` under the Electron lock, a
    fresh-context critic, `docs/load-bearing.md` entries from the cause, the suite rows in
    `docs/verify-suite-table.md` and `docs/verify-suites.md`, the ledger line in
    `docs/build-log/m248-m250-ledger.md`, one commit `feat(m250): …`.
