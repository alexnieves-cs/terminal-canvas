# M251 — packs, Phase A: plan

Spec: `docs/superpowers/specs/2026-09-10-m251-packs.md`. Every task below is test-first: the check is
written and run RED against the absent code before the code is written.

## T1 — the format, pure (`src/shared/pack.ts`)
- RED: `verify:file pack.manifest.1–.4`, `pack.build.1`, `pack.requires.1` (loaded through
  `scripts/file-entry.cjs`), watched failing on "pack.ts does not export …".
- GREEN: `PACK_VERSION`, `PACK_CONTENT_KINDS`, `buildPack`, `parsePack`, `packRequirements`,
  `remapPack`, `packSentence`.
- `verify:verbs gate.2` gains `shared/pack.ts` by name, with a comment.

## T2 — the reviewed preset (`layout-schema.ts`)
- RED: `verify:layout preset.reviewed.1` (absent stays absent, `false` kept, a non-boolean is
  kept, treated as unreviewed and warned by name).
- GREEN: `Preset.reviewed?: false`, parsed in the same shape as M190's template field.
- Main: `preset:spawn-by-id` and every spawn of a user preset refuse an unreviewed one by name.

## T3 — IPC
- `pack:read` and `pack:export` go into `ipc-contract.ts` first, then main (`ipc.ts`
  `PackHandlers` with an inert default, the real handlers in `index.ts`), then preload.
- Main computes requirements from `credentialStore.list()` and a PATH probe.
- The channel list in CLAUDE.md, the README diagram and `EXPECTED_CHANNELS` in `verify:ipc` are
  all updated.

## T4 — renderer
- `PackPreview` sheet. *Add* saves through the existing `template:save`, `prompt:save` and preset
  save paths, with fresh ids.
- The *I've read this* control for a workflow and for a preset.
- Palette rows `pack.import` and `pack.export`, and the verbs `import-pack` and `export-pack`
  (destructive), refused at the agent door.
- RED first: `verify:panels:product pack.import.1` (the preview adds nothing and spawns zero; *Add*
  makes unreviewed objects; the preset spawn is refused by name; mark-read clears the flag) and
  `pack.import.2` (the per-field missing-credential sentence).

## T5 — close
- `npm run verify` green, then `npm run shot` and a look at the preview sheet.
- Load-bearing entries, a ledger line and a fresh-context critic.
- Commit `feat(m251): …`, then `graphify update .`.
- Stop before Phase B.
