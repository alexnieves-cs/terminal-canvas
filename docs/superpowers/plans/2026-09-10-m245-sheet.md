# M245 plan — the `sheet` object

Spec: [../specs/2026-09-10-m245-sheet.md](../specs/2026-09-10-m245-sheet.md).
Checks first, watched failing (1/42 against the absent modules), then the modules.

## Tasks
1. **Checks** — `scripts/verify-sheet.cjs` + `scripts/sheet-entry.cjs`, registered as
   `verify:sheet`. Scoped ids: `sheet.csv.*`, `sheet.formula.*`, `sheet.model.*`,
   `sheet.grid.*`, `sheet.record.*`, `sheet.disk.*`, `sheet.xlsx.*`, `sheet.export.*`.
2. **Pure modules** (shared, plain node): `csv.ts` (lossless RFC 4180), `sheet-formula.ts`
   (addressing, lazy evaluator, reference shifting), `sheet-model.ts` (immutable edits, TSV),
   `sheet-grid.ts` (window arithmetic), `sheet.ts` (view parser, base64, summary),
   `sheet-xlsx.ts` (SheetJS read/write + named losses), `sheet-session.ts` (guarded file life).
3. **Bytes through main, no new channel** — `encoding?: 'base64'` on `FileReadRequest` /
   `FileWriteRequest`; `FileResult` gains a `bytes` arm only a base64 read can receive;
   `FileWatchers.watch` re-reads in the same encoding. Absent = the old text path.
4. **Persistence and the export gate** — `FileSource.sheet`, `parseFileSource` (drop the field
   on malformed), `makeFilePanel`, `layout-adapt` both directions, `portable` export + import
   strip to `sheet: {}`; canvas undo does not roll a sheet's source back.
5. **UI** — `SheetNode.tsx` (virtualized grid, formula bar, row/col insert/delete, resize,
   copy/paste/undo subscriptions, loss chip), `sheet-controllers.ts` (+ `sheetFocused()` in
   `shouldIgnoreKeys`), CSS beside the checklist's.
6. **Doors** — `CREATABLE_OBJECTS` `sheet` (pill row icon), `sheet-edit` verb with four doors,
   palette row `sheet.edit`, executor case, `TEAMMATE_REFUSED_VERBS`.
7. **Electron check** `sheet-clip.1` in `verify:panels` (product part): with a terminal on the
   canvas and a sheet cell focused, `edit:paste` lands in the sheet file and the terminal's
   PTY receives nothing; `edit:undo` restores the file.
8. **Alias question** — delete the alias, build, record the result (it is needed).
9. **Ledger, load-bearing entries, gate** (`npm run verify`), critic.
