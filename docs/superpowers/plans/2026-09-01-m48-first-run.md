# M48 — First run, and every empty state: implementation plan

Spec: `../specs/2026-09-01-m48-first-run-design.md`. Six tasks, check-first.
The report comes before the launcher, because the launcher's "found / not
found" line reads it and the probe banner is the cheapest, highest-value
line in the milestone.

## Task 1 — The report (`verify:tmux` `env.1`, `verify:ipc`)

`main/env-report.ts`: `buildEnvReport(facts)` — pure, plain-node: the
resolved PATH's entries, each CLI's path or absence (`claude`, `codex`,
`git`), the shell probe's outcome and reason, tmux's choice and reason, the
layout file's path and whether a `.bak` was written, env key NAMES only,
and `probedAt`. `env.1` RED against the missing module, then green.
`shell-env.ts` records the probe's outcome (it swallows the failure into a
fallback today and only logs); `index.ts` records the `.bak` write. The
`env:report` invoke: contract, preload, `ipc.ts` with an `envReport` dep
appended last with an inert default (the harness pattern), both diagrams.

## Task 2 — The list-typed setting (`verify:layout` `firstrun.1`)

RED, then `'list'` on `SettingDef` (`SettingValue` gains `string[]`),
`parsePreferences`/`writePreference` arms (a list of strings, dropped with a
warning otherwise), `hints.seen` default `[]`. The palette mints no row for a
list — hints are not a user setting — and says so where the enum's fall-
through comment already is.

## Task 3 — The Environment scope (`verify:palette` `firstrun.1`)

RED, then `buildEnvironmentRows(report)` exported from `commands.ts`: the
`manage.environment` door, and one information row per fact (shell, each
CLI found/absent, tmux, PATH entries, layout file, probed-at), each
`hiddenAtRest`, `scope: 'environment'`, `run: () => {}`. `PaletteScope`
gains `'environment'`; `SCOPE_LABEL` too.

## Task 4 — The launcher and the banner (`verify:panels` `firstrun.1/.2`, `env.1`)

RED, then: `firstRunPanels()` returns `[]` (an empty canvas is a designed
state; both call sites in `Canvas.tsx`); `Launcher.tsx` inside `.canvas`,
outside `.world`, rendered when the active workspace holds no panels and
the view is not merged — one control per preset through
`paletteActions.spawnPreset` (disabled with `REASON_NOT_ON_PATH` and an
install line), `Open a file…`, `New note…` (disabled: a note is saved in a
panel's directory), and the report's found/not-found line; `EnvBanner`
when `report.shell.ok === false`.

## Task 5 — The hint strip (`verify:panels` `firstrun.3`)

RED, then `HintStrip.tsx`: pan, zoom, `⌘K`, `⌘N`; each fades when its
gesture is first observed in Canvas (the viewport's translation moving,
its scale moving, the palette opening, the panel count growing) and is
written to `hints.seen`; a seen hint stays hidden across a reload.

## Task 6 — Every empty state, and close

The Files pane's no-cwd reason (which panel, and why nothing lists), the
context pane's "select a panel to inspect it" line; README (first run);
`docs/load-bearing.md` (keyed on `panels.length === 0`, never on activity;
the launcher calls the real create path; key names only in the report);
backlog #38 and #47 → done; suite counts; build log; `npm run verify`;
merge.
