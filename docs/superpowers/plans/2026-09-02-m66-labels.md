# M66 plan — every control says what it is

Spec: `docs/superpowers/specs/2026-09-02-m66-labels-design.md`.

1. **The text-scan checks** — `verify:rail labels.1/.2` (every `<button` in the renderer
   carries `aria-label`, `title` or visible text; every `.icon-button` site has a name),
   `verify:styles compact.1` (drawer z-order under the strips), `verify:palette voice.1`
   (setting descriptions in the palette's voice) and `rank.1` (a visible title match outranks
   a hidden-searchText match in the same section). Red where the code does not yet satisfy
   them; recorded honestly where it already does.
2. **The top bar and the dock** — the `Lanes` glyph for the merged view, `merged view ·
   read-only` beside it while on (`data-merge-label`), the hover title `Back to <workspace>`
   (`TopBar` gains `workspaceName`); the dock's `--on` left bar; the context toggle's
   `aria-pressed`.
3. **The canvas edge and the far view** — `EdgeIndicators` takes `labelOf` and renders a
   chip (`.edge-indicator__label`: name + `needs you`); the merged view's lane headers as
   screen-space `.lane-header` elements positioned from `worldToScreen`, the active lane
   saying `this workspace`.
4. **The rail** — `start` as a text control in the mono face (`.rail-row__start`), a fixed
   slot on every terminal row so the state words form a column; kind glyphs for the
   sessionless kinds.
5. **The context pane and the file panel** — the action bar as a grid (Restart full width,
   the three secondaries and Close on one row); the edit toggle's `--on` fill and
   `aria-pressed`.
6. **The compact breakpoint** — drawers from the top bar to the bottom of the shell; the
   HUD and the hint strip at `z-index: 950` on an opaque ground; the drawers' last rows padded
   past the strip band.
7. **The palette and the hint strip** — settings hints wrap (`settings-schema.ts` rewritten
   in the palette's voice); `VISIBLE_BONUS` in `matchCommand`; the strip's rule line as its
   last hint; the fit control's `fit` label at standard and wide.
8. **`verify:panels labels.3/.4`** red against the pre-M66 build, then green: the merged
   label and chrome-sized lane headers; an off-screen bell's pip carrying a chip.
9. **Shot at 1000/1440/1800, look, critic, verifier; build log; chain; merge; branch.**
