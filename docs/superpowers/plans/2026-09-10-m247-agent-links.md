   `agent-links.map.*`, `.store.*`, `.forget.*`, `.lod.*`.

   Never the registry's version counter.

   `indexToolFiles` → `agentLinks`) with the file panels as objects (`draftBy` from a sheet's
   pending draft), and publishes them; `forgetAgentLinksFor` beside every `clearAgentState`
   (the four Canvas sites and the palette's close loop), `forgetAllAgentLinks` at reset.
5. **Layer** — `AgentLinkLayer.tsx` inside `.world` beside `LinkLayer`; CSS for read / wrote /
   draft and the badge; the badge opens the sheet's draft review.
6. **Toggle** — setting `canvas.agentLinks` (default on) and verb `agent-links on|off|toggle`,
   four doors: palette `canvas.agent-links`, a canvas view control, `tc plan agent-links off`,
   an action node.
