# M42 — Search across every panel: implementation plan

Spec: `../specs/2026-09-01-m42-search-design.md`. Five tasks, check-first.

## Task 1 — The log's search (`verify:file`)

Checks `search.1–.3` per the spec against two panels' logs in the fixture
directory. RED (no `search` on the log). Then `ScrollbackLog.search(ids,
query, { maxHits, maxPerPanel })` in `main/scrollback-log.ts`: per panel,
read the whole file (≤ 2 MiB), strip, split, scan from the END so the newest
hits come first, stop at the per-panel cap; stop overall at the total cap.
An empty or whitespace query answers `[]` without opening a file.

## Task 2 — The channel (`verify:ipc`, `verify:meta`)

`scrollback:search` in the contract with `SearchHit` and `SearchRequest`
types; the handler passes the ids of every panel in every workspace
(`mergedWorkspaces()`), never a renderer-supplied list; preload;
`EXPECTED_CHANNELS` 59; both diagrams.

## Task 3 — The rows and the three empty states (`verify:palette`)

Checks `search.1–.3` per the spec. RED. Then: `PaletteScope` gains
`'search'`; `PaletteContext` gains `searchQuery`, `searchResults`
(`SearchHit[] | null` — null before the first answer) and
`scrollbackEnabled`; `commands.ts` builds `search.hit.<panelId>.<index>`
rows in group `panel`, scope `search`, plus the two disabled empty-state
rows (`REASON_SEARCH_OFF`, `REASON_SEARCH_NO_MATCHES`).

## Task 4 — `Cmd+F`, the query report, the debounce (`verify:panels`)

Check `search.1` per the spec. RED. Then: `usePalette` opens with scope
`search` on `Cmd+F` (matched on `event.code === 'KeyF'`, standing down
like `Cmd+K` does); `Palette.tsx` calls `props.onSearchQuery(query)` when
the scope is `search`; Canvas holds `searchQuery`/`searchResults`, debounces
120 ms, invokes, and clears both when the scope leaves `search`; the
`scrollback.persist` value reaches the context through the settings reload
the frame already re-reads.

## Task 5 — Close

README (the Keyboard table row, a "What it does" sentence in the scrollback
bullet), `docs/load-bearing.md` (the index is the log, searched by main; a
hit moves the camera never the terminal), backlog #16 → gone, suite counts,
build log, `npm run verify`, merge.
