## Goal

Every surface asks the same pure modules what needs you, what belongs to which task, which zoom tier you are in, and where a canvas point sits on the World floor. That is how "one attention story" and "one spatial truth" become true by construction.

| Module (new) | Contract |
|---|---|
| `src/shared/attention-queue.ts` | `buildQueue(inputs) → AttentionItem[]`, ordered and pure. Kinds: `approval`, `question`, `shell-prompt`, `failed`, `recovery`. Each item has a sentence, a since time, a task id and a primary verb. `next(id)` / `prev(id)` for ⌘J / ⌘⇧J. It reads the same facts `panelState` reads, so the words cannot disagree. |
| `src/renderer/session/useAttentionQueue.ts` | The one selector, subscribed to `agent-state-store`, `live-session-store` and the decision inbox. The pill, dock badge, Sessions tab count, edge pips, minimap dots and World all read it. |
| `src/renderer/canvas/task-regions.ts` | Builds on `task-clusters.ts` and `task-members.ts`. Region bounds = union of member rects + 24px padding, snapped to the 24px grid, 20px radius. Label = ticket, title, agent count, criteria done/total. Hit-testing and "move region moves members" as one undo. |
| `src/renderer/canvas/zoom-tier.ts` | `tierFor(scale, prev)`: Work ≥ 0.70, Plan 0.25–0.70, Map < 0.25, with ±0.03 hysteresis. `TIER_TARGET` scales for ⌘1/2/3. `cardIdsForTier()` feeds `lod.ts`'s existing `cardIds` input, so no PTY lifecycle changes. |
| `src/shared/world-space.ts` | `canvasToFloor(p) = {x: p.x/100, z: p.y/100}` and its inverse. `viewportToCamera(viewport, size, tier)` / `cameraToViewport(...)` round-trip within 1 canvas px. Pitch per tier: Work close, Plan room view, Map near top-down. |
| `scripts/fixtures/rd-steward/` | The demo workspace from the mockups: five tasks (Ledger CSV export SW-412, Plaid webhook retry SW-398, Infra, Steward web · pricing, Steward mobile · onboarding crash SW-421) with agents in every state, plus a world-sim feed script for the World scenes. Fixture only; never product copy. |

## Acceptance

- All modules are pure and checked in plain node (`verify:rd-f2`): queue order and stability, next/prev wraparound, region bounds and snap, tier hysteresis (no flapping at 0.70±0.02), and world-space round-trip error < 1px over 1,000 random points and viewports.
- `rd-attn.one.1` (source-text check): the pill, dock badge and Sessions count import `useAttentionQueue`. None of them computes its own count. The pill and the dock exist today; the Sessions count lands with L-D, so the check names the import sites that exist when you merge and the Sessions host F3 adds. If a site does not exist yet, say so in the check comment rather than inventing a file you do not own.
- Entering Plan or Map with a focused terminal first releases focus, using the same path as ⌘Esc. A check proves no keystroke can reach a card (the `lod.ts` invariant).
