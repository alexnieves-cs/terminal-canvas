## Goal

Five task terraces at their canvas positions. Robots and consoles show state rings, eyes and screens. Amber beacons rise from three waiting agents, and the failed Codex slumps with a red ring. Handoff arcs, file tiles, the plan whiteboard and orbiting sub-agents. The bottom pill and the 2D minimap with the camera wedge are shared with the canvas.

Files. `WorldStructure.tsx` + `world-structure.ts` (terraces from `task-regions.ts` × `canvasToFloor`), `WorldOffice.tsx` (desks for agents, consoles for plain shells, at panel positions), `WorldPlatform.tsx`, `WorldProps.tsx`, `world-scene.ts`, `world-set.ts`, `WorldRobot.tsx` (poses: typing, raised arm, slump), `WorldCard.tsx` and `WorldCardBody.tsx` (density layers; M431 moved the plain-DOM half into `WorldCardBody` so the flat room can share it), `WorldChrome.tsx` (retire the "Ask your team" pill, the legend and Fit room, and mount the shared pill, minimap and tier controls), `WorldView.tsx`, `world-perf.ts` / `world-quality.ts` (keep instancing and level of detail).

- `rd-world.layout.1`: every terrace centre and size equals `canvasToFloor` of its region. Every desk or console sits at its panel's floor point. Dragging a terrace runs the same region-move verb as 2D, with one undo, and the 2D canvas shows the move.
- State: working = cyan eyes, ring and screen, gently breathing. Needs-you = raised arm, amber ring and an amber vertical beacon (the only beacon). Done = green ring. Failed = slumped with a red ring and a red pill ("Exited 1 · lint failed"). Idle = slate.
- Density: name pills with a state dot at rest. Ask chips only for waiting agents ("Wants to edit ledger.ts", "3 to add · approve?"). Full cards only for the picked agent, which fixes the six-card clutter. Terrace label: "Ledger CSV export · SW-412 · 2/4".
- Shared chrome: the title bar (Canvas active), the bottom pill "3 need you · 1 failed · 4 working · Go ⌘J · Ask an agent ⌘L", the 2D minimap with a camera wedge, and the Work / Plan / Map switch plus Follow at bottom left. `rd-world.chrome.1` is a source check that these are the same components as 2D.
- Performance: 20 agents hold the `world-perf.ts` budget. Total WebGL contexts (xterm live budget 8 + World 1) stay well under 16.
