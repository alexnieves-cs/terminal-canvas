## Goal

Every surface reads state colour from one closed set. A Tone in `panel-state.ts` maps to a `--state-*` token in `styles.css` and to a hex in `src/shared/state-palette.ts` for WebGL and canvas-2D readers. The Obsidian material is re-valued to the concept table.

| Tone (`panel-state.ts`) | Word | Token | Dark value | Rule |
|---|---|---|---|---|
| `working` (+ `starting`, breathing) | working | `--state-working` | `#5BE1E6` | Also the brand accent and focus. D1 decides the selection treatment. |
| `needs-you` | needs you | `--state-needs` | `#F5B544` | The only tone that glows (edge + soft glow; in the World, the only vertical beacon). |
| `done` (D7: watcher passed, work done, auto done) | exited 0 / passed / done | `--state-done` | `#5EDC9A` | Green means finished OK. It never means "working" again (the M415 inversion ends). |
| `exited` (non-zero, signal, error) | exited N / failed | `--state-failed` | `#FF6B6B` | Paired with one fix verb (screen 09). |
| `idle`, `asleep`, `none`, `kind` | idle / asleep / not started / kind | `--state-idle` | `#8C94A5` | Slate. Asleep keeps its dashed left edge. |
| (not a tone) external / Codex · smart guides | — | `--external` · `--guide` | `#A78BFA` · `#FF5FA2` | Guides appear only while arranging, never at rest. |

Material re-valuation (dark theme): ink `#08090D`, canvas `#0B0D12` with a 24px dot grid `#1B202A`, surfaces `#11141B` / `#161A23` / `#1C2130`, hairlines `rgba(255,255,255,.07/.12)`, text `#E7EAF0` / `#8C94A5` / `#5B6375`. Radii: panels 12, controls 8, regions 20, pills full. Add `--dur-flight: 220ms` with ease-out. Light-theme values are re-derived against contrast check 11, not copied.
