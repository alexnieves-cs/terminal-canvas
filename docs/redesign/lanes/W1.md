## Goal

The 2D plan tilts back into the floor, terraces rise, and robots pop up nearest-first. A cancel chip, the 2D | World lens and a filmstrip explain the move. Reduced motion uses a 120 ms cross-fade.

Files. `world/world-transition.ts` (still one pure clock: add the plan tilt, terrace rise and nearest-to-focus stagger; reduced motion becomes a 120 ms cross-fade instead of a snap), `WorldStage.tsx`, `world-toggle.ts` (⌘⇧W via the registry), the Canvas host seam (opacity and tilt of the 2D layer), a new `world/WorldLens.tsx` (the 2D | World ⌘⇧W segmented control at the canvas's top left), and a new `world/plan-floor.ts` (draws the floor texture from layout data, not from a screenshot).

- The move takes 1000 ms with easeInOutCubic, and every reader samples the same `WorldTransition`. The 2D plan and the 3D floor coincide at the hand-off frame, because both use `world-space.ts` (the max misalignment check passes within 2 px at 1440×900).
- Terraces rise from the floor, and robots pop nearest-first from the camera target, with `popDelays` measured from the target, not from the room centre.
- The cancel chip reads "Entering World · Esc cancel" with progress. Esc mid-move reverses at the same speed (the existing ramp property). Toggling back lands the 2D viewport on the camera's target spot (`cameraToViewport`).
- Reduced motion: a 120 ms cross-fade with no dolly, tilt or pop. The canvas stays mounted throughout, terminals keep running (a pid check), and keys never reach the hidden canvas.
- The old TopBar "World view" button is removed through a `requests.md` item to the lead (TopBar is frozen with F3). If `verify:world` / `verify:panels` select `.shell__world-toggle`, the lens keeps that class.
